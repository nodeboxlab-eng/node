문의 양식

플랫폼, 버전, 원하는 API 조건선택 후 작성한 양식 복사하기 버튼을 누르시면 내용이 복사됩니다.

원하시는 API를 체크한 뒤 발동될 개수를 입력해 주세요. 예) 별풍선 10개가 들어오면 치즈가 날아옵니다.

권리귀속 — 공유해드린 모든 작업물의 저작권 및 지적재산권은 제작자(Node68)에게 귀속됩니다. 타인에게 공유 및 재배포 시 저작권법 위반으로 법적 대응이 이루어질 수 있습니다.

포트폴리오 활용 — 모든 작업물은 제작자의 포트폴리오 & 홍보 등에 사용될 수 있습니다.

신청 절차 — 주문 완료 후 일정을 조율하고, 작업이 시작됩니다.

환불 규정 — 작업 시작 전: 전액 환불 가능합니다. / 작업 시작 후: 환불이 불가능합니다.

작업 시작 안내

작업은 결제 완료 및 작업에 필요한 파일 전달이 모두 완료된 순서대로 진행됩니다.

완료 예정일 안내

일정 여유를 위해 완료 요청일은 작업 시작일 기준 1개월 이후로 설정 부탁드립니다.

실제 작업 기간은 작업 내용 및 일정 상황에 따라 안내된 기간보다 짧게 소요됩니다.

커스텀 API 제작 안내

현재 개인 전용 독점 커스텀 API 제작은 접수 받고 있지 않습니다.

판매 중이지 않은 기능이나 연출을 원하시는 경우, 문의해주시면 제작 가능 여부를 검토해드립니다.

작업물 및 관련 자료 이용 안내

API 연출 및 세팅을 위해 제공되는 프롭, 파티클, 노드, 블루프린트 및 관련 코드는 Node68이 자체 제작한 창작물입니다. 해당 자료는 저작권 양도나 소유권 이전이 아닌, 해당 API 사용을 위한 제한적 대여 형식으로 제공됩니다.

제공된 자료는 지정된 API 외의 용도로 사용할 수 없으며, 타 작가의 API 제작·세팅·연출에 참고자료로 활용하는 행위는 금지됩니다.

또한 프롭, 파티클, 노드 구조, 블루프린트, 코드, 세팅값 등 작업물과 관련된 모든 자료를 캡처·녹화·복제·공유·전달·양도·재배포·판매하거나, 타 작가 및 제3자에게 공개하는 행위는 엄격히 금지됩니다.

위반 행위가 적발될 경우, 이용 제한 및 작업 중단 조치가 이루어질 수 있으며, 사안에 따라 저작권 침해 및 영업상 손해에 대한 법적 대응이 진행될 수 있습니다.

색상 안내

각자 사용 중이신 조명, 배경, 사용 환경에 따라 Prop, Particle 등의 색상은 예시 이미지와 다르게 보일 수 있습니다.

이용 규약 변경 관련 안내

본 안내사항 및 이용 규약은 운영 상황에 따라 사전 예고 없이 변경·갱신될 수 있습니다.

변경된 이용 규약은 갱신 이후 제공되는 모든 상품 및 이용 행위에 적용됩니다.

API 세팅을 신청하거나, 세팅 작업 및 관련 자료를 제공받은 경우 본 안내사항과 이용 규약의 내용을 확인하고 이에 동의한 것으로 간주됩니다.
